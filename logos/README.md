### Fonts

Text in the lockup SVGs uses:
- **Noto Serif SC** (weight 300) — 文海坐标 — Google Fonts
- **EB Garamond** (weight 400) — MAP OF STORIES — Google Fonts

SVG text renders correctly in any browser with internet access.
For print or offline use, install both fonts locally first, or ask
for a paths-only (text-to-outline) version.

### Favicon

Drop `favicon-32.svg` into your `<head>` as:
```html
<link rel="icon" type="image/svg+xml" href="/favicon-32.svg">
```
